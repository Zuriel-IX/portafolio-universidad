Clase 11

  1. ¿Google Sites es un CMS?
  • Sí: Google Sites es una plataforma para crear y gestionar sitios web con editor WYSIWYG, plantillas y gestión de páginas; funciona como un CMS sencillo (más tipo SaaS/site builder que un CMS autohospedado como WordPress/Drupal).
  1. Otros CMS de código abierto
  • WordPress, Drupal, Joomla, (y plataformas más especializadas como Magento/PrestaShop para e‑commerce).
  1. ¿Cuál es el módulo CMS de Dolibarr y qué permite hacer?
  • Dolibarr incluye un módulo “CMS / Website” para crear y publicar el sitio web (público o intranet) desde el ERP; permite usar plantillas, editor visual o HTML/CSS, organizar contenido con contenedores/plantillas reutilizables, previsualizar sin servidor externo y exponer contenido dinámico desde los datos del ERP.
  1. ¿En Dolibarr existe un gestor documental? ¿Para qué sirve y qué muestra?
  • Sí: Dolibarr dispone de funciones de gestión documental (módulo/núcleo de documentos y complementos DMS disponibles en Dolistore) para almacenar y organizar archivos, enlazarlos a terceros, proyectos, facturas, productos, controlar accesos/versión mínima y buscar/visualizar adjuntos desde las fichas relacionadas; hay módulos adicionales que amplían categorías, versionado y reglas de compartido.
